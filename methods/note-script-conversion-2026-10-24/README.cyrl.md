# Кирилица в краткых примєтках

[Латиница](README.md) · [Програм Python](project_note.py) · [Полны прєводник писма](../../project_isv_cyrillic_v8.py)

Програм прєображаје кратке меджусловјанске примєткы из латинице в кирилицу. Функција `project_note` даје кирилске формы седми примєток к §7 статје31 Emmy Noether. Цєлы меджусловјанскы прєклад има два писма; кирилска форма не јест другы прєклад.

## Употрєба

Трєбны јест Python 3. Дополнитељни пакеты не сут потрєбни. Входны фајл има кодовање UTF-8.

```text
python project_note.py notes-latin.tex notes-cyrillic.tex
```

Другы фајл јест резултат. Јест ли он уже створјены, програм јего не замєњаје.

## Правила и обсег

Охрањаје имена команд LaTeX, наслов `Idealtheorie` и римско число `II`. Буквы осталого текста прєображаје по табели в програму, с оддєлными правилами за `dž`, `lj`, `nj` и јих формы с великоју почєтноју буквоју. Историчне буквы `ѧ` и `ѫ` сут техничне одговарјајуче формы за `ę` и `ų` в тој функцији; не сут честју стандардној кирилској абецеды.

Функција не разпознаваје математичне области, адресы URL ани произвољне аргументы команд. Она јест за те кратке примєткы; за цєлы документ употребите полны прєводник писма. Математичне означења можно охранити с [оддєлным програмом](../source-identifiers-2026-10-24/README.cyrl.md).

Стандардне одговарјајуче буквы и обє абецеды описује [Jan van Steenbergen, правопис меджусловјанского језыка](https://interslavic.fun/learn/orthography/). Та функција охрањаје своје точно записане правила за повторјење резултата.
